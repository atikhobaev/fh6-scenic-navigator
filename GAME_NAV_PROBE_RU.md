# FH6 Game Nav Asset Probe v1.12

Диагностический сканер для поиска **внутренних navigation / traffic / lane / junction ресурсов Forza Horizon 6**.

Он нужен для следующего этапа FH6 Scenic Navigator: попробовать получить реальные данные об односторонних съездах, направлениях полос и разрешённых переходах на сложных городских развязках.

## Безопасность

Probe работает **только на чтение**:

- не изменяет файлы Forza Horizon 6;
- ничего не внедряет в процесс игры;
- не запускает модификацию `MediaPC`;
- не копирует игровые assets в отчёт;
- в shareable-отчёте сохраняются только **относительные имена файлов**, размеры, найденные ключевые слова и короткие текстовые/строковые фрагменты.

Большие бинарные файлы не загружаются целиком: стандартный режим читает только ограниченные куски начала/середины/конца файла и имеет общий лимит бинарного сканирования.

## Самый простой запуск

1. Распакуй архив в отдельную папку.
2. Запусти `probe_game_nav_assets.bat`.
3. Если FH6 найдена автоматически — сканирование начнётся само.
4. Если игра не найдена, вставь путь к папке FH6 и нажми Enter.

Можно также **перетащить папку FH6 прямо на `probe_game_nav_assets.bat`**.

Примеры папок:

```text
D:\SteamLibrary\steamapps\common\ForzaHorizon6
D:\SteamLibrary\steamapps\common\Forza Horizon 6
D:\XboxGames\Forza Horizon 6\Content
```

## Что отправить обратно

После завершения появится папка:

```text
probe_output
```

В ней будет файл:

```text
FH6_Game_Nav_Probe_Report.zip
```

**Пришли именно этот ZIP в чат.**

Внутри только три отчёта:

- `fh6_nav_asset_report.json` — полный структурированный отчёт;
- `fh6_nav_asset_report.txt` — удобный для чтения список лучших кандидатов;
- `fh6_nav_candidates.tsv` — таблица кандидатов для сортировки/анализа.

## Что ищет сканер

По именам файлов/каталогов и содержимому:

```text
navigation
nav
lane
junction
intersection
oneway / one_way
traffic
route
direction
spline
road
AI
roadlink
transition
turn restriction
road graph
```

Для XML/JSON/INI/TXT и других текстовых форматов сохраняются только строки, где встречаются интересующие термины.

Для бинарных файлов извлекаются читаемые ASCII и UTF-16LE строки, содержащие такие термины.

## Более глубокий режим

Если обычный отчёт не найдёт нужных данных, можно открыть CMD в папке probe и запустить:

```bat
probe_game_nav_assets.bat "D:\SteamLibrary\steamapps\common\ForzaHorizon6" --deep
```

`--deep` читает более крупные ограниченные выборки бинарных packages и работает заметно дольше. Сначала используй стандартный режим.
